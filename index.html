用途與適用範圍

本應用程式是個人使用的旅遊領隊口碑整理工具，依 Threads API 實際授權範圍搜尋公開貼文，將貼文中的服務經驗分類、整理成存放於使用者電腦的報表。分類呈現發文者的說法，不表示指控已獲證實，亦不作為單獨決定個人聘用、派團或去留的依據。

取得及產生的資料

本工具取得 API 回傳的貼文識別碼、文字、發文時間與原文連結。貼文文字可能包含作者主動公開的姓名或其他資訊。工具另產生分類、判斷原因、證據片段及執行狀態紀錄。使用者提供的 Threads 存取權杖儲存在本機設定檔，用於向 Meta 驗證 API 請求；本工具不要求提供 Threads 密碼。

資料使用與分享

資料用於關鍵字搜尋、重複貼文排除、口碑初篩及人工覆核。本工具預設以本機規則分析，不將貼文傳送 AI 服務。若營運者另外啟用 OpenAI 分析，貼文文字將傳送至 OpenAI API 處理，適用該服務的資料條款；程式將回應儲存選項設定為 store=false，但這不等同保證供應商不保留任何服務紀錄。本工具沒有出售資料或自動將報表發布到公開網站的功能。

保存與安全

權杖、報表及執行日誌儲存在使用者電腦。目前版本沒有自動到期清除機制，資料會持續保存至營運者手動刪除；因此刪除請求須由營運者人工處理。本機權杖設定檔限制存取權，且權杖、報表及日誌列入 Git 忽略清單；其他備份軟體仍可能另行備份資料，由營運者管理。公開 GitHub Pages 僅用於本隱私政策，不應包含權杖、貼文原始資料或監測報表。

刪除、更正與撤回授權

如希望申請刪除或更正本工具保存的資料，請透過上方聯絡信箱提供相關貼文網址及申請內容，不需寄送密碼、權杖或無關證件。營運者將在確認請求範圍與必要身分後，人工檢查並處理持有的報表及適用備份，回覆處理結果。若原始公開貼文仍存在，未來搜尋可能再次取得；營運者應就已受理的刪除請求安排後續排除措施，目前版本尚未提供自動排除清單。

使用者可在 Threads／Meta 提供的應用程式授權管理介面撤回授權；在本機刪除權杖並停用排程，可停止本工具後續擷取。撤回授權不會自動刪除先前儲存在電腦上的報表。刪除 Threads 原始貼文須由貼文作者在 Threads 處理，本工具無法代為刪除平台上的內容。

隱私政策網站

本頁由 GitHub Pages 提供託管服務，GitHub 可能依其隱私聲明記錄訪客 IP 位址等服務與安全資訊。本頁未加入分析追蹤程式、廣告、登入或資料收集表單。詳見 GitHub 隱私聲明。

政策更新

資料來源、分析供應商、保存方式或用途如有變動，營運者應同步更新本頁並標明更新日期。
